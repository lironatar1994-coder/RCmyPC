חזרה לפאנל

הפאנל הזה מאפשר להמשיך כל שיחה של Claude במחשב מהטלפון, גם כשלא נמצאים ליד המחשב.

פעם ראשונה

  1. למצוא את הסיסמה: במחשב, בקובץ QQL\data\secrets.json. שם המשתמש: liron, הסיסמה בשורה "password".
  2. להתחבר: לפתוח בטלפון את lawebs.co.il/rc ולהיכנס. הכניסה נשמרת ל-30 יום.
  3. להוסיף למסך הבית: הפאנל מציע את זה לבד. באייפון: בספארי, כפתור השיתוף ⬆︎ ואז "הוספה למסך הבית". באנדרואיד: כפתור Install, או התפריט ⋮ ואז "הוספה למסך הבית".

שימוש רגיל

  1. לפתוח את הפאנל. למעלה צריך להופיע PC online עם נקודה ירוקה.
  2. רשימת השיחות נטענת לבד מהמחשב. אפשר לחפש בשדה החיפוש.
  3. ללחוץ על שיחה. המחשב פותח אותה ב-Claude ומפעיל Remote Control (בערך 5 שניות).
  4. ללחוץ על "Open in Claude". השיחה נפתחת באפליקציית Claude בטלפון.

מה צריך במחשב

  • המחשב דלוק ומחובר למשתמש. מסך נעול זה בסדר.
  • Claude לא חייב להיות פתוח: כפתור Start Claude פותח אותו.
  • לא צריך להפעיל כלום: הסוכן עולה לבד בכל כניסה ל-Windows ומונע מצב שינה.

אם משהו לא עובד

  • PC offline באדום: המחשב כבוי, במצב שינה, או שהסוכן לא רץ. במחשב להריץ: powershell -File agent\install.ps1 (מתוך התיקייה QQL).
  • Cloud session: שיחת ענן כבר זמינה בטלפון. ללחוץ Open Claude Code ולמצוא אותה שם.
  • שגיאה שאין כפתור Remote Control: בשיחה עוד לא נשלחה הודעה. לשלוח בה הודעה אחת ואז לנסות שוב.
  • לא ברור מה קורה: ללחוץ 🖥 ולראות את מסך המחשב.

בלי טלפון, מהמחשב

להריץ rc.cmd בתיקייה QQL: מופיעה רשימה ממוספרת, מקלידים מספר והשיחה מתחברת.
